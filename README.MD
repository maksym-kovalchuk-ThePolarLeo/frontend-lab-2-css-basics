# Frontend Lab

A small practice project demonstrating a simple HTML/CSS/JavaScript page with a
responsive layout and a basic interactive feature (a click counter button).

## Features

- Header, paragraph, button, content block, and footer.
- Responsive layout that adapts between desktop and mobile viewports.
- A button that counts and displays the number of clicks.
- A theme toggle button that switches between light and dark mode.

## Running locally

1. Clone or download this repository.
2. Open `index.html` directly in your browser, **or** serve it locally, e.g.:
   ```bash
   npx serve .
   ```
3. (Optional) Install dev dependencies to use lint/format tooling:
   ```bash
   npm install
   npm run lint
   npm run format
   ```
